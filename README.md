# Programming Practicum: Java, Swing and MVC

Six Java assignments by James Fischer from a programming practicum course (TCSS 305, Autumn 2024). Starter code written by course staff is credited in each file's `@author` tags.

| Folder | Focus |
|---|---|
| `a1-clock-shop` | Clock model, file I/O, JUnit tests |
| `a2-shapes` | Shape hierarchy with abstract classes, interfaces and a factory |
| `a3-bookstore` | Shopping-cart model with item pricing and bulk discounts |
| `a4-road-rage` | Traffic simulation: vehicle inheritance and movement rules |
| `a5-color-adjuster-gui` | Swing GUI with listeners and property-change events |
| `a6-craps-gui` | Craps game built as a Swing GUI, separate model/view/controller |

**Run:** import a folder as a Java project (JDK 17+) and run its `main` class; tests use JUnit 5.
