Assignment Overview:
This assignment focuses on practicing key object-oriented programming concepts like inheritance, visibility, and the implementation of interfaces. We'll create an inheritance hierarchy of shapes, starting with an abstract class, AbstractShape, which will provide basic structure and enforce implementation of methods like area() and name(). We then build concrete classes like Circle, Square, Rectangle, and Triangle, ensuring proper encapsulation, final fields, and constructor validation. We'll also implement the Comparable interface and override equals() and hashCode() methods. The ShapeFactory class will provide static methods for creating these shape objects, and a ShapeTester class will test, sort, and display the shapes.
