Assignment Overview:
The assignment aims to create a Clock and ClockShop class that can efficiently manage and work with several clock objects. The Clock class provides methods for setting the time, advancing the time, and formatting output. It acts as a representation of a single clock, encapsulating its state through hours, minutes, and seconds. The validity and adherence to the 24-hour format of all time values must be guaranteed by this class.

In contrast, the ClockShop class serves as a container for several Clock objects, enabling actions like adding, deleting, and accessing specific clocks. It is intended to make the management of clock collections easier. One feature that makes this possible is the ability to load the shop from a file, enabling the testing of multiple situations with varying clock configurations.
