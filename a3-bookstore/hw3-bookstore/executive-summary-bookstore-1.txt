Assignment Overview:
The purpose of this assignment is to create a bookstore management system that handles user credentials, inventory management, and shopping functionality. It involves implementing key features such as user authentication (login and registration), loading configuration files for different campus stores, and managing product inventory for those stores. The system aims to simulate a real-world bookstore experience by allowing users to log in, view items available for sale, and potentially place items in a shopping cart.

The scope of the project includes multiple components such as reading and writing to files, processing user inputs, and ensuring secure credential storage using hashing and salting techniques. A significant aspect of the assignment is working with file I/O for loading data like user credentials and campus inventory from external files. Additionally, the project involves creating a graphical user interface (GUI) to enhance user interaction with the system, making it more accessible and user-friendly.
